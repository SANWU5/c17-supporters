# 头像

将允许公开展示的头像放在这个目录中，建议：

- 使用稳定用户 ID 命名，例如 `p001.webp`、`p002.png`。
- 使用正方形图片，建议 256 × 256 像素，尽量控制在 100 KB 内。
- 支持 PNG、JPG、JPEG、WebP；文件名使用小写英文字母、数字、下划线或短横线。
- 在名单中填写相对路径，例如 `"avatar": "avatars/p001.webp"`。
- 暂无头像时填 `null` 或省略 `avatar` 字段，由应用显示默认头像。

请勿直接上传包含其他人、聊天内容或支付信息的截图。更换头像后应递增名单的 `revision`，应用据此刷新缓存；也可以使用新文件名避免旧图片缓存影响展示。
